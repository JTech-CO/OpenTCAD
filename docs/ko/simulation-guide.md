# TCAD와 OpenTCAD의 시뮬레이션

[English](../en/simulation-guide.md) · [OpenTCAD](../../README.ko.md) · [문서](../README.ko.md)

## TCAD란 무엇인가요?

TCAD는 **Technology Computer-Aided Design**의 약자로, 물리 모델을 이용해 반도체 제조 공정과 소자의 동작을 분석하는 기술입니다. 아이디어마다 실제 시편을 만드는 대신 모델의 입력을 바꾸고 예측된 동작을 확인할 수 있습니다.

서로 연결된 두 가지 질문을 다룹니다.

- **공정 시뮬레이션:** 제조 조건에 따라 재료의 영역과 도펀트 분포가 어떻게 달라지는가?
- **소자 시뮬레이션:** 구조·재료·도핑·전극이 주어졌을 때 전압에 따라 어떤 전류와 내부 분포가 나타나는가?

소자 솔버는 구조를 **메시(mesh)** 라는 작은 구간이나 셀로 나누고 그 위에서 방정식을 풉니다. DEVSIM은 편미분 방정식을 유한체적법으로 풉니다. [공식 소개](https://devsim.org/introduction.html)를 참고하세요. 메시를 세분화하면 이산화 오차를 평가하는 데 도움이 되지만, 빠진 물리 모델을 보충하지는 못합니다.

TCAD는 단순히 2D 단면을 그리는 도구가 아닙니다. SPICE 같은 회로 시뮬레이터와도 다릅니다. 현재 OpenTCAD는 여러 부품을 연결한 회로나 칩 배치가 아니라 개별 소자를 실험합니다.

## 어떤 실험을 선택하면 되나요?

| 기능 | 바꾸는 입력 | 결과 | 실행 위치 |
|---|---|---|---|
| 해석식 NMOS 계산기 | 치수, 기판 도핑, 이동도와 전압 | 전류, 문턱 전압, 트랜스컨덕턴스와 I-V 곡선 | GitHub Pages를 포함한 브라우저 |
| 1D PN 접합 | 길이, p/n 도핑, 면적, 순방향 전압과 메시 | I-V, 전위와 전자·정공 분포 | 로컬 DEVSIM |
| 2D NMOS 템플릿 | 게이트 길이, 산화막 두께, 폭, 도핑, 바이어스와 세분화 | 드레인 I-V와 삼각형 메시의 전위·캐리어·도핑 지도 | 로컬 DEVSIM |
| SUPREM 공정·소자 연계 | 지원 주입·열처리 조건과 선택형 절연막 증착 | 공정 구조와 후속 2D 소자 해석에 미치는 영향 | 별도 로컬 SUPREM CLI 실행 후 DEVSIM |
| 참조 작업공간 | 설명용 프로젝트, 바이어스와 외부 데이터 | 참조 도면과 가져온 데이터의 비교 | 솔버 실행 없는 브라우저 |

한 솔버의 결과를 다르게 보여주는 것이 아니라 서로 다른 계산 경로입니다. 계산기는 즉시 갱신되지만 네이티브 솔버는 사용자가 실행을 요청해야 하며 시간이 걸리거나 수렴에 실패할 수 있습니다. 저장된 결과를 표시하는 것은 새 시뮬레이션이 아닙니다.

## 1. 즉시 계산하는 NMOS 계산기

NMOS 트랜지스터는 **게이트** 전압으로 **소스**와 **드레인** 사이의 전류를 제어합니다. 게이트 산화막은 게이트와 반도체를 분리하며 **바디**는 기판 영역입니다.

채널 길이·폭, 산화막 두께, 기판 도핑, 이동도, 평탄대 전압, 게이트-소스 전압 VGS, 드레인-소스 전압 VDS, 바디 바이어스 VSB를 바꾸면 개략도·I-V 곡선·문턱 전압·트랜스컨덕턴스를 다시 계산합니다.

- **문턱 전압:** 모델에서 강한 반전이 시작되는 기준 전압입니다.
- **드레인 전류:** 설정한 전압과 치수에서 모델이 예측하는 전류입니다.
- **트랜스컨덕턴스(gm):** 게이트 전압 변화에 전류가 얼마나 민감하게 반응하는지 나타냅니다.

다른 입력을 고정하고 폭을 늘려 보세요. 이 모델에서는 전류가 폭에 비례합니다. 다음으로 산화막 두께나 바디 바이어스를 바꾸며 문턱 전압과 곡선을 확인하세요. 실제 실리콘 측정값이 아니라 조건을 통제한 모델 실험입니다.

계산기는 300 K에서 장채널·강한 반전을 가정하는 제곱법칙 근사입니다. 공간 메시를 풀지 않습니다. 문턱 아래 전도, 단채널 효과, 채널 길이 변조, 양자 보정과 온도 스윕은 포함하지 않습니다. 문턱 아래 전류는 이상화된 표현이지 누설 전류 예측이 아닙니다.

[계산기 상세 설명과 설치](mvp-laboratory.md)

## 2. PN 접합 소자 시뮬레이션

PN 접합은 p형과 n형 반도체가 맞닿는 구조입니다. 로컬 템플릿은 한 공간 방향을 따라 전위와 전하 운반자의 이동을 계산합니다. 색상 지도로 보여도 **1D 데이터**이며 2D 소자 해석이 아닙니다.

접합 길이, 억셉터·도너 농도, 단면적, 최종 순방향 전압과 메시 수를 설정하세요. DEVSIM을 실행하면 순방향 I-V 스윕과 전위·전자·정공 분포를 얻습니다.

입력 범위는 길이 1~10 μm, 양쪽 도핑 각각 1e15~1e17 cm^-3, 면적 1~100 μm², 최종 순방향 전압 0~0.5 V, 메시 구간 100/200/400개입니다. 300 K, 이상적인 옴 접촉, Poisson 방정식과 전자·정공 연속 방정식, 일정한 이동도와 SRH 재결합을 사용합니다.

다른 조건을 고정한 채 면적 두 가지를 비교해 보세요. 이어서 메시를 200구간과 400구간으로 바꾸고 전류가 안정적인지 확인할 수 있습니다. 각 경우를 직접 실행하고 결과 파일을 보관하세요.

역방향 항복, 터널링, 자체 발열과 공정에서 가져온 접합 도핑은 지원하지 않습니다. 입력 범위 안의 모든 조합에서 수렴을 보장하지는 않습니다.

[PN 실행, 모델 상수와 재실행](mvp-laboratory.md)

## 3. 실제 2D MOSFET 시뮬레이션

로컬 2D 템플릿은 실리콘·산화막 NMOS 단면을 삼각형 메시에서 해석합니다. 설명용 그림 위에 해석식 곡선을 얹는 기능이 아닙니다.

기본 템플릿에서는 게이트 길이, 산화막 두께, 소자 폭, 기판·소스/드레인 도핑, 게이트 전압, 최종 드레인 전압과 메시 세분화를 바꿀 수 있습니다. 다음 결과를 확인합니다.

- 드레인 전압에 따른 드레인 전류
- 단면 내부의 정전위
- 전자와 정공 농도
- 순 도핑, 메시와 전극 위치

게이트 길이 0.5~2 μm, 폭 1~100 μm, 산화막 5~30 nm, 게이트 전압 0~1.5 V, 드레인 전압 0~0.5 V를 지원합니다. 소스와 바디는 0 V이며 온도는 300 K로 고정됩니다.

기본 조건의 결과를 저장하고 게이트 전압을 바꿔 다시 실행하세요. 전류와 채널의 캐리어 분포를 비교할 수 있습니다. 드레인 전압 스윕은 한 해석에 포함되지만 여러 게이트 전압은 각각 별도 실행해야 합니다. 작은 차이를 물리적 효과로 해석하기 전에 메시 세분화도 확인하세요.

Poisson·드리프트-확산 방정식에 SRH 재결합과 일정한 이동도를 사용합니다. 고전계 이동도, 양자 보정, 축퇴 통계, 충돌 이온화와 터널링은 제외됩니다. 나노미터급 FinFET이나 임의 재료에 검증된 모델이 아닙니다. 폭은 2D 단자 전류를 환산하며 계산을 3D로 바꾸지 않습니다. 가독성을 위해 그림의 가로·세로 축척이 다를 수 있습니다.

[2D 모델, 동작 범위와 수치 검사](mos-process.md)

## 4. SUPREM 공정·소자 연계 실험

이 고급 실험 경로는 **공정 조건으로 도펀트 분포가 바뀌면 소자 전류는 어떻게 달라지는가?** 를 살펴봅니다.

명시적으로 활성화한 고정 레시피 CLI와 별도로 설치한 신뢰 가능한 SUPREM 또는 호환되는 로컬 컨테이너 이미지가 필요합니다. 브라우저에서 공정 덱을 실행하는 서비스는 아닙니다.

1. 지원되는 마스크 주입·열처리 레시피를 실행하며 주입량·에너지·열처리 시간·온도 등을 설정합니다.
2. 생성된 구조와 출처 파일을 보관합니다.
3. 구조 파일과 필요한 전극 파일을 지정해 로컬 소자 서비스를 시작합니다.
4. 2D 화면에서 해당 가져오기 모드를 선택하고 DEVSIM을 실행합니다.
5. 다른 공정 조건도 직접 실행한 뒤 결과를 비교합니다.

두 전달 모드의 목적이 다릅니다.

- **활성 도핑 가져오기:** 지원 활성 도펀트 값을 기본 소자의 실리콘 메시에 보간합니다. 원본 공정 형상을 보존하는 방식이 아닙니다.
- **원본 메시와 전극:** 지원 실리콘·산화막 삼각형과 노드 도핑을 보존하고, 구조 해시에 연결된 명시적 전극 경계를 사용합니다. 형상·도핑은 파일에서 가져오며 폭·게이트 전압·드레인 전압만 편집할 수 있습니다.

기본 실리콘 레시피는 게이트 산화막을 성장시키지 않습니다. 선택형 절연막 레시피는 산화막 증착·식각이며 열산화가 아닙니다. 지원하지 않는 구조는 임의로 복구하지 않고 거부합니다. 범용 다층 공정 편집, 임의 전극 자동 추론, 완전한 GUI 공정·소자 파이프라인은 구현되지 않았습니다.

서비스는 시작할 때 공정 파일의 스냅샷을 읽습니다. 디스크 파일을 바꿔도 소자가 자동으로 다시 계산되거나 파일이 다시 로드되지 않습니다.

[공정 CLI와 도핑 전달](mos-process.md) · [원본 메시와 전극](process-mesh.md)

## 결과를 올바르게 읽는 방법

- **출처 표시**를 확인하세요. 해석식 추정, 실제 DEVSIM 출력, 저장 결과, 미검증 외부 데이터와 참조 데이터는 다릅니다.
- **I-V**는 인가 전압에 따른 전류이며, **바이어스**는 전극에 설정한 전압입니다.
- **도핑**은 도너·억셉터 농도이고 **캐리어**는 소자 모델에서 계산한 전자·정공입니다. 같은 값이 아닙니다.
- 단위를 확인하세요. 치수는 μm 또는 nm, 농도는 cm^-3, 전류는 A 등을 사용합니다. 전류 밀도와 단자 전류는 다릅니다.
- 그래프의 매끄러움뿐 아니라 수렴, 전류 보존과 메시 세분화 결과를 확인하세요.
- 비교 전에 모델·형상·단위·입력 조건을 맞추세요. 차이가 있다고 곧바로 오류나 개선을 뜻하지 않습니다.

[참조 작업공간](m4-workspace.md)은 설명용 프로젝트와 데이터 확인 기능입니다. 덱을 편집해도 SUPREM을 실행하지 않으며 바이어스를 바꿔도 참조 곡선을 다시 계산하지 않습니다. 모의 실행·복구 버튼도 실제 솔버 작업이 아닙니다.

## 저장, 재현과 자동화

Windows 로컬 MVP는 저장된 PN·2D 결과 재열기, 호환되는 최종 전류 비교와 JSON 내보내기를 제공합니다. 오프라인 체크섬 백업·복원과 서비스 재시작 시 중단 판정도 지원합니다. 상태 폴더마다 최대 32개 작업을 보관하므로 한도에 도달하기 전에 [Windows 운영 안내](windows-mvp.md)를 확인하세요.

재현을 위해 입력, 결과 JSON, 일치하는 OpenTCAD 리비전, 솔버 버전, 공정·전극 파일을 보존하세요. 재실행 검사는 내용 무결성을 확인하고 선언된 허용오차로 수치 항목을 비교합니다. 같은 해시는 같은 내용의 근거이지 물리적 정확도나 작성자를 증명하지 않습니다.

선택형 [로컬 MCP](mcp.md)는 신뢰하는 클라이언트에 기능·결과 조회를 제공합니다. 실행·취소에는 명시적 활성화가 필요합니다. 스윕 계획은 최대 8개 조건을 검증하지만 자동으로 대기열에 넣거나 실행하지 않습니다. AI는 실험 조정을 도울 수 있으며 솔버나 수치 검증을 대체하지 않습니다.

## 현재 보장하지 않는 범위

현재는 교육·수치 실험 범위의 Windows 우선 로컬 MVP 후보이며 다른 운영체제에는 실험용 설치 경로를 제공합니다. 제조 공정 승인 도구, 보정된 계측기, 범용 3D 소자 도구, 회로 시뮬레이터, 다중 사용자 호스팅 솔버나 솔버 포함 원클릭 설치 프로그램은 아닙니다. 기반 솔버가 더 넓은 기능을 지원하더라도 OpenTCAD UI는 현재 AC·과도 해석이나 임의 소자·물리 모델 정의를 제공하지 않습니다.

정적 웹사이트는 계산기를 실행하며 네이티브 SUPREM·DEVSIM을 실행하지 않습니다. 물리적 전원 차단 인증과 독립 기관은 일반 출시의 필수 조건이 아니며 인증받았다고 주장하지도 않습니다. 배포하거나 확장하기 전에 [릴리스 범위](product-scope.md)와 [라이선스](licensing.md)를 확인하세요.
