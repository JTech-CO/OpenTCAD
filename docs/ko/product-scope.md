# OpenTCAD 제품 및 릴리스 범위

[English](../en/product-scope.md) · [Windows MVP](windows-mvp.md)

## 2026년 9월 12일 프로젝트 책임자가 확인한 방향

OpenTCAD은 일반 컴퓨터에서 한영 웹 UI로 사용하는 개방형 반도체 공정·소자
시뮬레이션 플랫폼을 목표로 합니다. 전용 시험장비나 기관의 자격 승인을 사용의
전제 조건으로 삼지 않습니다. 연구용 모델, 재현 가능한 결과, 자동화와 전용 MCP는
개발 방향이며, 현재 전문 계측장비와 동등하거나 제조 공정 승인에 필요한 보정
정확도를 확보했다는 주장은 아닙니다.

정적 GitHub Pages는 즉시 해석식 계산기와 참조 UI를 실행합니다. 실제 SUPREM·DEVSIM
실행에는 현재 로컬 솔버 서비스가 필요합니다. 웹에서 사용한다는 의미가 네이티브
솔버를 이미 정적 브라우저 페이지 안에서 실행한다는 의미는 아닙니다. 다중 사용자
호스팅 서비스나 브라우저 전용 솔버 이식은 별도의 구현·검증이 필요합니다.

## 일반 소프트웨어 릴리스 기준

- 모델 한계를 명시한 파라미터 편집, 그래프와 공간 분포 표시
- 버전 고정 의존성과 출처를 갖춘 지원 범위 내 로컬 솔버의 처음부터 끝까지 실행
- 수치 회귀, 반복 재현성, 결과 재실행과 명시적 허용오차
- 인증된 실행, 취소, 프로세스·런처 종료 복구, 결과 무결성과 백업·복원 검증
- 정확한 리비전에 대한 Windows 인수 시험과 개발자 검토, 한영 안내

물리적 전원 차단, PDU·릴레이 장비, 전문 시험기관과 독립 기관 검토는 이 릴리스
트랙의 필수 조건이 아닙니다. 소프트웨어 비정상 종료 시험은 유지하며, 실제 전원
차단 내구성을 인증하는 것으로 표현하지 않습니다. 기존 8개 게이트의 M3 자격 검증은
선택적 추가 신뢰성 검증 트랙으로 보존하며 일반 OpenTCAD 출시 전 의무가 아닙니다.
기존 증거, 런타임 권한과 비활성 상태는 바꾸지 않습니다. 해당 구성요소를 일반
트랙에서 재사용할 때는 범위에 맞는 통합 검증을 수행하며 보안 검사를 우회하지 않습니다.

[Windows 기준 파일](../../validation/manifests/windows-mvp-release.json)은 아직
릴리스 후보입니다. 개별 사건의 종결이 전체 릴리스 승인을 뜻하지 않습니다.

## 과거 PN 사건

사용자는 Codex 동시 작업 중 다른 서브에이전트가 로그를 변경해 값이 손상되었으며,
다른 프로젝트에서도 같은 유형의 사건을 확인했다고 설명했습니다.
[종결 기록](../../validation/experimental/pn-incident-disposition-20260912.json)은
이 사용자 보고를 근거로 과거 릴리스 차단을 해제합니다. 당시 원본 결과 쌍이 없어
독립적인 원인 재구성은 할 수 없습니다. 기존 관측 기록은 수정하지 않습니다.
정확한 해시 검사, 수치 허용오차와 실패 원본 보존을 유지하며 새 불일치는 별도로 조사합니다.

## 원본 앱 및 솔버 라이선스

사용자는 [tcad-webapp](https://github.com/ypooh2042/tcad-webapp) 개발자에게 직접
연락하여 원본 앱이 MIT 라이선스라는 확인을 받았다고 설명했습니다. 이는 사용자에게
전달받은 확인이며, 공개 라이선스 파일을 검증했거나 OpenTCAD이 원저작자의 허가를
대신 작성했다는 의미는 아닙니다. 확보되는 개발자 서면 확인, 적용 리비전과 출처를 보존합니다.

이 확인은 원본 웹앱에 관한 것이며 모든 솔버·의존성에 일괄 적용되지 않습니다.
구성요소별 조건과 고지는 유지합니다. 현재는 소스 배포와 사용자 설치 솔버를 사용하며,
솔버 포함 이미지·설치 패키지를 배포할 때는 구성요소 목록, 해당 고지와 재배포 검토가
필요합니다. 수치 회귀와 재현성은 소프트웨어 품질 조건으로 유지하지만 corpus를
외부 전문기관에서 승인받도록 요구하지 않습니다.

## 후속 개발 순서 (계획이며 구현 완료 아님)

1. 일반 Windows 인수 시험과 릴리스 검토를 완료합니다.
2. 공정·소자 통합 흐름, 이력 재열기, 파라미터 스윕, 비교·내보내기 UI를 개선합니다.
3. 검증된 작업 서비스 위에 전용 로컬 MCP를 추가합니다. 기능 조회, 입력 스키마,
   실행·상태·취소, 결과·출처 조회와 제한된 스윕을 제공합니다. 읽기 전용부터 시작하고
   계산·쓰기에는 명시적 권한을 요구합니다. 임의 shell, Python, 파일 경로는 노출하지 않습니다.
4. 재료·구조·물리 모델과 수치 기준 사례를 확장하고 제공하는 기능·플랫폼별로
   재현 가능한 시험을 수행합니다.

AI는 검증된 솔버 작업을 조정하고 출처를 설명하는 역할을 맡으며, 솔버 출력을
지어내거나 AI 답변을 수치 검증으로 취급하지 않습니다.
