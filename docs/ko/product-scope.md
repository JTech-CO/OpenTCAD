# 제품 및 릴리스 범위

[English](../en/product-scope.md) · [시뮬레이션 안내](simulation-guide.md) · [Windows 설치](windows-mvp.md)

## 현재 범위

OpenTCAD은 일반 컴퓨터에서 반도체 교육·수치 실험을 수행하는 것을 목표로 합니다. 현재 소스에는 즉시 계산기, 고정 로컬 PN·2D MOSFET 템플릿, 실험용 SUPREM 전달, 결과 이력과 초기 로컬 MCP 연결기가 있습니다. 영어가 기본이며 한국어를 지원합니다.

Windows 11 x64 로컬 MVP는 별도 설치 솔버를 사용하는 **소스 배포 릴리스 후보**입니다. [릴리스 매니페스트](../../validation/manifests/windows-mvp-release.json)는 아직 `candidate-not-released`이며 책임자의 릴리스 승인이 없습니다. Pages 배포가 정식 솔버 제품 출시를 뜻하지는 않습니다.

[전용 Windows 인수 기록](../../validation/experimental/windows-mcp-acceptance-20260912.json)은 구현 리비전 `8b84ce7`의 네이티브 Windows·솔버·MCP, 프런트엔드와 브라우저 검사를 통과한 기록입니다. 해당 구현은 현재 `main`에 병합되었으며 `e51a96f`의 Pages 배포도 완료됐습니다. 기록에 남아 있는 병합·공개 대기는 검토 당시의 상태입니다. 책임자의 최종 릴리스·버전 승인과 릴리스 태그는 남아 있습니다. 과거 증거는 다시 쓰지 않습니다.

## 일반 소프트웨어 릴리스 기준

- 모델 한계를 명시한 파라미터 편집, 그래프와 공간 분포
- 버전 고정 의존성과 출처를 갖춘 지원 범위 내 로컬 솔버의 전체 실행
- 수치 회귀, 재실행과 명시적 허용오차
- 인증된 실행, 취소와 소프트웨어 비정상 종료 복구
- 무결성 검사, 오프라인 백업·복원과 한영 운영 안내
- 정확한 구현에 대한 Windows 인수와 책임자의 명시적 릴리스 결정

2026년 9월 12일 프로젝트 책임자가 정한 범위에 따라 전용 전원 제어 장비, 물리적 전원 차단 검증과 독립 기관은 일반 출시의 **필수 조건이 아닙니다**. 수치 검사와 소프트웨어 복구 검사는 유지합니다.

기존 M3 OCI 자격 검증은 별도의 선택적 신뢰성 검증 트랙입니다. 매니페스트, 증거와 비활성 릴리스 프로필은 그대로 유지하며 미승인 기능이 MVP에서 자동 활성화되지 않습니다.

## 공개해야 할 한계

GitHub Pages는 계산기와 참조 UI를 실행하며 네이티브 솔버를 실행하지 않습니다. 실제 해석에는 로컬 서비스가 필요합니다. SUPREM은 명시적 CLI와 지원 구조 전달을 사용하며 임의 브라우저 공정 편집기가 아닙니다. MCP 스윕 계획은 대기열을 자동 실행하지 않습니다.

현재 범위는 macOS·Linux 제품 자격, 물리적 전원 차단 내구성, 동일 사용자에 의한 변조 방어, OS 보호 롤백 방지, 인증·암호화된 MVP 백업이나 자동 예약 MVP 백업을 보장하지 않습니다. 오프라인 백업은 체크섬 기반입니다.

물리 모델은 제한적이며 제조 측정값에 맞춰 보정된 것이 아닙니다. OpenTCAD은 제조 공정 승인 도구가 아니며 전문 계측장비와 동등하다고 주장하지 않습니다. [지원 실험과 제외 범위](simulation-guide.md)를 확인하세요.

## 배포와 출처

OpenTCAD 고유 코드와 문서는 MIT이며 외부 솔버의 라이선스를 바꾸지 않습니다. 솔버 소스나 바이너리는 포함하지 않습니다. 솔버를 포함한 이미지·설치 프로그램에는 별도의 구성요소 검토와 고지가 필요합니다. [라이선스 안내](licensing.md)를 참고하세요.

책임자는 원본 `tcad-webapp` 개발자에게 직접 MIT 사용을 확인했다고 보고했습니다. 이는 사용자에게 전달받은 확인이며 공개 라이선스 파일을 독립 검증한 것이 아니고 모든 솔버 의존성을 포함하지도 않습니다. 서면 확인과 적용 리비전을 확보하면 보존합니다.

과거 PN 불일치와 이후 장비 메타데이터 원인 재현·수정은 [PN 반복 재현성](pn-repeatability.md)에 기록되어 있습니다. 원본 관측은 보존하며 정확한 해시 검사와 수치 검사를 완화하지 않았습니다.
