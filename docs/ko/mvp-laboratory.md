# 소자 실험실 MVP

[English](../en/mvp-laboratory.md)

소자 실험실은 제한된 교육용 범위에서 즉시 NMOS 계산, 실제 로컬 DEVSIM PN 접합
해석, 수치 검증과 결과 재실행이라는 세 가지 기준을 구현합니다. SUPREM-IV.GS부터
DEVSIM까지 연결하는 전체 공정·소자 제품은 아닙니다. M3 활성화, 이미지 재배포,
실제 전원 차단 자격 검증, 승인된 수치 corpus는 기존 상태를 유지합니다.

선택형 DEVSIM 패키지와 헬퍼는 Apache-2.0이며 상위 패키지의 LICENSE·NOTICE를
따릅니다. NumPy와 Windows MKL·런타임 의존성도 각 설치 패키지의 고지를 따릅니다.
저장소에 솔버 소스나 바이너리를 복사하지 않습니다. Git에서 제외한 로컬 환경은
OpenTCAD MIT 라이선스로 변경되거나 M3 재배포 승인을 받는 것이 아닙니다. 고정된
M0 의존성 목록은 유지하며 실험용 requirements는 별도 선택형 의존성 집합입니다.

## 즉시 계산 시작

Node.js 22 또는 24와 npm 10 이상에서 `npm ci`, `npm run dev`를 실행합니다.
출력된 주소를 열고 **소자 실험실 열기**를 선택하거나 `#lab`으로 바로 진입합니다.
같은 계산기는 GitHub Pages 정적 빌드에서도 Python이나 Docker 없이 동작합니다.
공개 사이트는 `main`을 따르므로 개발 브랜치가 자동으로 배포되지는 않습니다.

채널 길이·폭, 산화막 두께, 기판 도핑, 이동도, 평탄 밴드 전압, VGS, VDS, VSB를
바꾸면 전류, 문턱 전압, 트랜스컨덕턴스, I-V 곡선과 개략도가 다시 계산됩니다.
잘못된 입력에서는 기존 결과를 현재 결과처럼 남겨 두지 않습니다. 도면은 개략도이며
수치 해석 메시가 아닙니다.

`long-channel-nmos-300K-v1`은 내부 SI 단위, 300 K, ni = 1e10 cm^-3,
실리콘 상대 유전율 11.7, 산화막 상대 유전율 3.9를 사용합니다. 문턱 전압은
VFB + 2φF + γ√(2φF + VSB), φF = kT/q ln(NA/ni)입니다. 전류는 장채널 강한 반전
제곱 법칙, gm은 게이트 전압에 대한 미분입니다. 문턱 아래 전류, 단채널·양자 효과,
채널 길이 변조, 이동도 저하, 온도 스윕, 공정 보정은 포함하지 않습니다. 입력한 이동도는
스윕 중 일정하며 도핑에서 자동 산출하지 않습니다.
[MIT MOSFET/GCA 강의](https://ocw.mit.edu/courses/6-012-microelectronic-devices-and-circuits-fall-2009/resources/mit6_012f09_lec10/)에서
기본 근사를 확인할 수 있습니다.

## 실험용 로컬 솔버 설치

64비트 Python 3.12부터 3.14를 사용합니다. 실험실 CI는 Python 3.12를 사용합니다.
저장소 안에서 환경을 만듭니다. 다음 명령은 PyPI에서 제3자 패키지를 설치하며
OpenTCAD 승인 OCI 이미지를 설치하는 것이 아닙니다. 각 패키지의 조건을 확인하세요.

Windows PowerShell:

```powershell
python -m venv .venv-mvp
.\.venv-mvp\Scripts\python.exe -m pip install -r backend/app/experimental/requirements.txt
npm ci
npm run build
npm run test:mvp:solver
npm run local:lab
```

macOS / Linux:

```bash
python3 -m venv .venv-mvp
.venv-mvp/bin/python -m pip install -r backend/app/experimental/requirements.txt
npm ci
npm run build
npm run test:mvp:solver
npm run local:lab
```

기본 인터프리터는 `.venv-mvp`이며 `OPENTCAD_LAB_PYTHON`으로 변경할 수 있습니다.
DEVSIM은 2.11.0으로 고정합니다. Windows의 MKL과 관련 의존성 버전도 고정하며
한글 저장소 경로에서도 가상환경 내부 DLL을 찾도록 구성했습니다. 필요한 컴파일러
런타임이나 플랫폼 wheel이 없다면 [DEVSIM 설치 안내](https://github.com/devsim/devsim/blob/main/INSTALL.md)를
확인하세요. 로딩 실패를 해석식이나 모의 결과로 대체하지 않습니다.

Vite 주소가 아니라 **`local:lab`이 출력한 전체 주소**를 엽니다. 주소 조각에는 실행마다
달라지는 개인용 접근 토큰이 있습니다. 페이지는 이를 읽은 뒤 주소에서 제거합니다.
원래 주소를 공유하지 마세요. 새로고침 후 다시 연결하려면 원래 주소를 다시 엽니다.
Ctrl+C로 서버를 종료합니다. 서비스는 실제 평형 해석이 성공해야 준비 상태를 알립니다.
`local:serve`는 별도의 M3 승인형 제품 명령으로 유지됩니다.

## PN 접합 해석과 결과 확인

전체 길이, 억셉터·도너 농도, 단면적, 최종 순방향 전압, 메시 구간 수를 설정하고
**DEVSIM 해석 실행**을 누릅니다. 인증된 loopback API가 수치 입력을 받아 제한된
네이티브 솔버 프로세스를 시작합니다. 완료되면 전류, 전위, 전자·정공 농도 및 계산된
1D 전위 공간 지도를 표시합니다. 이 지도는 2D 해석이 아닙니다. 별도 NMOS 계산기는
DEVSIM MOSFET 템플릿이 아니며 공정 덱 편집기가 PN 솔버에 연결되지 않습니다.

PN 템플릿은 DEVSIM `simple_physics` 헬퍼로 Poisson 및 전자·정공 연속 방정식을
풉니다. 이상적인 옴 접촉과 SRH 재결합을 사용합니다. p영역은 x < L/2, n영역은
중앙점을 포함하는 나머지 영역입니다. 단면적으로 1D 전류 밀도 A/cm²를 전류 A로
변환합니다. 고정값은 300 K, ni = 1e10 cm^-3, μn = 400 및 μp = 200 cm²/Vs,
전자·정공 수명 1 μs, εSi = 11.7 ε0입니다. 바이어스는 0부터 최대 0.025 V씩 증가합니다.

입력 범위는 길이 1..10 μm, 도핑 1e15..1e17 cm^-3, 단면적 1..100 μm²,
최종 전압 0..0.5 V, 메시 100/200/400구간입니다. 이는 입력 허용 범위이며 모든 조합의
수렴·정확성을 보증하지 않습니다. 항복, 자체 발열, 터널링, 축퇴 통계, 공정 유래 도핑은
제외합니다. [DEVSIM PN 예제](https://github.com/devsim/devsim/blob/main/examples/diode/diode_1d.py)를 참고하세요.

실행 중 입력은 잠깁니다. 취소는 자식 프로세스를 종료하고 회수합니다. 해석은 한 번에
하나, 최대 60초, 진단·출력 합계 2 MiB로 제한하며 서버 재시작 전 최대 32개 작업을
보관합니다. 실패한 해석에 성공 결과를 표시하지 않습니다. 통신 실패는 취소 성공이
아니므로 취소 또는 상태 다시 확인을 사용하세요. 이 모드는 OS 샌드박스, 영속 브로커,
재시작 안전 작업 서비스가 아닙니다. 코드가 소유한 고정 템플릿만 실행하고 사용자
덱·Python·셸 명령·경로를 받지 않습니다. 기존 서버의 loopback, Host, Origin,
Bearer 인증, 요청 크기 검사를 재사용합니다.

## 저장과 재현

**입력과 결과 저장**은 JSON 파일을 내려받습니다. 계산기·솔버 파일 모두 API 토큰을
포함하지 않습니다. 브라우저 입력은 자동 저장하지 않으므로 이동·새로고침 전에 저장하세요.
**계산 입력 불러오기**는 입력을 먼저 검토하고 명시적으로 교체하게 합니다. 파일에 저장된
결과를 새 계산 결과로 신뢰하거나 표시하지 않습니다. PN 파일을 불러온 뒤 DEVSIM을
다시 실행하면 같은 입력으로 해석할 수 있습니다.

솔버 기록에는 입력, 상수, 단위, 템플릿 SHA-256, 솔버 버전, OS·Python 정보, 입력
SHA-256, 수치 배열, 실행별 검사, 결과 SHA-256이 포함됩니다. 해시는 내용 식별자이며
작성자·물리적 정확성·제품 승인을 보증하지 않습니다. 저장소에서 가상환경의 Python으로
저장한 파일을 다시 계산하고 비교할 수 있습니다.

```bash
python -m backend.app.experimental.replay path/to/opentcad-pn-result.json
```

재실행은 기록 무결성, 템플릿·버전·입력을 확인하고 실제 솔버 결과 배열을 비교합니다.
정확히 같은 기록과 수치적으로 일치하는 기록을 구분합니다. 상대 허용 오차는 1e-8이며
필드별 절대 허용 오차를 보고서에 표시합니다. 템플릿 변경 시 이전 기준선을 암묵적으로
승인하지 않고 새 결과를 요구합니다.

## 완료 기준 검사와 한계

- `npm run test:mvp`: 해석식 기준값, 연속성, 치수 비례, 기판 효과, UI 입력·결과 연결,
  잘못된 입력, 로컬 전송 및 결과 계약을 검사합니다.
- `npm run test:mvp:solver`: 실제 솔버, 인증된 HTTP 전체 경로, 취소·시간 초과 정리,
  반복 결과 해시, 파일 재현, 평형 질량 작용 법칙, 단면적 비례, 도핑 응답, 전류 보존,
  메시 세분화를 검사합니다.
- `npm run check`: 의존성 없는 실험 API 테스트를 포함한 회귀 검사입니다. 네이티브
  솔버 검사는 로컬에서 명시적으로 실행하며 별도 실험실 CI에서는 필수 실행합니다.

기본 2 μm 접합에서 200/400구간 메시의 전류 차이가 2% 미만이고 100/400구간 차이보다
작아야 합니다. 평형 경계 전압은 kT/q ln(NA ND/ni²)와 1e-7 V 이내로 일치해야 합니다.
각 바이어스에서 접촉 전류 밀도 불균형은 1e-8 A/cm² + 두 접촉 중 큰 전류 밀도의
1e-5배 이하여야 하며 `maxCurrentToleranceRatio`는 1 이하여야 합니다. 이는 제한된
모델과 구현의 검증이며 실제 실리콘 정확성이나 M3 corpus 승인이 아닙니다.

최초 Windows 검사에서 200/400구간 전류 차이는 약 0.104%, 평형 경계 오차는
약 5.2e-14 V였고 반복 결과 해시는 동일했습니다. 별도 CI는 Windows·macOS·Linux에서
수치 검사를 실행하며 Docker/Podman 자격이나 실제 전원 차단 승인을 부여하지 않습니다.
