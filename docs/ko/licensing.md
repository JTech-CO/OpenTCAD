# 라이선스와 배포 경계

[English](../en/licensing.md)

## OpenTCAD 고유 작업

루트 MIT 라이선스는 이 저장소를 위해 작성된 OpenTCAD 고유 애플리케이션 코드와 문서에 적용됩니다. 최초 GitHub Pages 애플리케이션은 전부 이 경계 안에 있으며 업스트림 애플리케이션이나 솔버 코드를 복사해 포함하지 않습니다.

## MIT 라이선스가 적용되지 않는 범위

OpenTCAD MIT 라이선스는 다음 항목의 조건을 바꾸지 않습니다.

- SUPREM-IV.GS 소스, 데이터, 매뉴얼, 예제 또는 파생 바이너리
- Gmsh와 GPL 의무
- DEVSIM과 Apache-2.0 고지
- base image, 패키지 의존성 또는 향후 가져오는 업스트림 애플리케이션 코드

검토한 SUPREM-IV.GS 업스트림 고지는 MIT 라이선스가 아니며 상업적 거래와 관련된 제한을 포함합니다. 따라서 관리자가 배포 결정을 문서화하고 필요한 검토 또는 허가를 받기 전에는 SUPREM 소스 archive, 사전 빌드 이미지 또는 번들 installer를 게시하지 않습니다.

## 기반 릴리스 결정

이번 기반 릴리스에는 제3자 솔버 소스나 바이너리를 포함하지 않습니다. 정적 UI는 OpenTCAD을 위해 만든 결정론적 참조 미리보기 데이터를 사용하며 솔버 출력을 재현한다고 주장하지 않습니다. 따라서 제3자 시뮬레이터를 다시 라이선스한다는 오해 없이 MIT 애플리케이션 기반과 문서를 게시할 수 있습니다.

## 솔버 배포 전 게이트

솔버 이미지나 installer를 게시하기 전에 다음을 추가하고 검토해야 합니다.

1. 구성요소별 저작권·라이선스 목록
2. 정확한 소스 출처와 patch-set hash
3. 필요한 경우 source offer 또는 source build 경로
4. 이미지별 포함·재배포 결정
5. NOTICE와 attribution 자료
6. 승인되지 않은 이미지를 거부하는 SBOM 및 release manifest 검사

이 문서는 엔지니어링 경계를 기록하며 법률 자문이 아닙니다.
