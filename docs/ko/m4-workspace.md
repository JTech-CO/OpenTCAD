# M4 작업공간: 프로젝트, 탐색, 비교

[English](../en/m4-workspace.md)

M4는 M3 제품 활성화 없이 구현할 수 있는 작업공간 기능을 제공합니다. 정적 빌드와
로컬 미리보기는 같은 프런트엔드를 사용합니다. M3는 미승인 상태이며 프로젝트 파일,
외부 결과, 모의 동작으로 런타임 권한을 부여할 수 없습니다. 이 브랜치의 구현이
공개 `main` 배포에도 이미 반영되었다는 뜻은 아닙니다.

## 프로젝트 사용 흐름

1. 작업공간에서 프로젝트 이름을 입력합니다.
2. **공정**에서 설명용 덱을 편집합니다. 진단 항목을 선택하면 해당 줄로 편집기
   초점이 이동합니다. 알 수 없는 문법은 경고입니다. 전체 SUPREM 문법 검사,
   엔진 준비 상태 확인 또는 수치 타당성 검증은 아닙니다.
3. **소자**에서 게이트·드레인 전압과 온도를 편집합니다. 미리보기 입력 범위는
   -10부터 10 V, 1부터 1500 K이며 솔버에서 검증한 동작 범위가 아닙니다.
4. **프로젝트 파일 저장**으로 `opentcad-project.json`을 내려받습니다.
5. **프로젝트 파일 열기**는 검토할 내용을 먼저 표시합니다. **현재 프로젝트 교체**를
   선택해야 기존 내용을 교체합니다. 가져오기 취소나 오류 발생 시 기존 편집 내용은 유지됩니다.

프로젝트 JSON의 필드는 정확히 `format: "opentcad-project"`, `schemaVersion: 1`,
`name`, `deck`, `bias`입니다. `bias`에는 `gateVoltage`, `drainVoltage`,
`temperature`만 들어갑니다. 이름은 1부터 80자, 덱은 최대 65,536자입니다. 덱 검사는
최대 2,000줄을 다루며 진단은 최대 100개 표시합니다. 오류를 먼저 표시하므로 경고가
많아도 차단 오류가 숨겨지지 않습니다. 덱 문법이 잘못된 초안도 저장할 수 있지만
오류가 남아 있으면 모의 워크플로를 시작할 수 없습니다.

영속 저장 수단은 파일입니다. 프로젝트, 외부 결과, 작업 상태를 브라우저 저장소나
서버에 자동 저장하지 않습니다. 새로고침 전에 저장하고 원본 결과 파일도 보관하세요.
다운로드에는 프로젝트 입력만 들어가며 API 토큰, 승인 기록, 재개 가능한 실제 작업은
포함되지 않습니다.

## 소자 탐색

참조 NMOS 도면에서 재료·전극 선택, 100%부터 400% 확대, 범위가 제한된 방향 이동,
포인터 드래그, 키보드 방향키를 지원합니다. 도면 영역에 초점을 두고 `+`와 `-`로
확대·축소하며 `Home`으로 전체 도면을 맞춥니다. 키보드로 선택 상자와 버튼을
조작할 수 있으므로 포인터 없이도 같은 영역 선택이 가능합니다.

참조 형상과 참조 곡선은 설명용 데이터입니다. 덱이나 바이어스를 편집해도 다시
계산하지 않습니다. 영역 형상, 층 두께, 소자 응답을 시뮬레이션 결과로 해석하면 안 됩니다.

## 결과 파일 가져오기

**비교**의 **파일 형식과 예제**에서 I-V, 프로파일, 재료 배치도 JSON 예제를
내려받을 수 있습니다. 예제는 솔버 결과나 자격 검증 증거가 아닙니다. JSON과 CSV는
올바른 UTF-8이어야 하며 파일당 1 MiB, 현재 작업공간에서 최대 8개까지 보관합니다.
중복 JSON 키, 알 수 없는 필드, 비유한 숫자, 과도한 배열, 지원하지 않는 단위는
표시 전에 거부합니다.

CSV는 따옴표 필드와 별도 메타데이터가 없는 두 열 숫자 형식입니다.

```csv
vd_v,id_ma_per_um
0,0
0.5,0.1
1,0.2
```

프로파일은 정확히 `depth_um,concentration_cm-3` 머리글을 사용합니다. 곡선은
2부터 2,000개 점을 가지며 x가 엄격히 증가해야 합니다. 농도는 양수, 깊이는 0
이상이어야 합니다. x 범위는 ±1e6이며 깊이는 0부터 시작합니다. y 범위는 ±1e30이며
프로파일의 최소 농도는 1e-30입니다.

곡선 JSON 형식은 다음과 같습니다.

```json
{
  "format": "opentcad-result",
  "schemaVersion": 1,
  "kind": "iv",
  "name": "External run",
  "source": "Unreviewed source description",
  "xUnit": "V",
  "yUnit": "mA/um",
  "points": [[0, 0], [1, 0.2]]
}
```

프로파일은 `kind: "profile"`, `xUnit: "um"`, `yUnit: "cm^-3"`를 사용합니다.
프로파일의 y축은 로그, I-V의 y축은 선형입니다. 그래프 눈금이 반올림되어도
표본 표에서는 원래 숫자 값을 확인할 수 있습니다.

구조 JSON은 `kind: "structure"`를 사용하고 `xUnit`, `yUnit`, `points` 대신
`unit: "um"`, 양수 `width`, `height`, `regions`를 갖습니다. 영역은 1부터 64개이며
각 영역은 정확히 `id`, `material`, `x`, `y`, `width`, `height`를 갖습니다. ID는
중복될 수 없고 직사각형이 전체 범위를 벗어나면 안 됩니다. 원점은 왼쪽 위이며 y는
아래로 증가합니다. 겹치는 직사각형은 파일 순서대로 그려 나중 영역이 위에 놓입니다.
전체 치수는 1e-9부터 1e6 μm, 영역 크기는 최소 1e-12 μm입니다. 일반 메시 파서가
아닌 직사각형 재료 배치도입니다. 네이티브 `.str`, `.msh`, `.vtk`와 임의 솔버
형식은 지원하지 않으며 암묵적으로 솔버 변환을 수행하지 않습니다.

파일의 출처 설명이 무엇을 주장해도 모든 결과는 **미검증 외부 데이터**로 남습니다.
파일명, 미검증 출처 설명, 원본 바이트의 SHA-256을 표시합니다. Web Crypto를 사용할
수 없으면 해시를 사용할 수 없다고 명시합니다. 해시는 출처, 물리적 타당성, 라이선스,
수치 기준선의 검증이 아닙니다. 파일을 로컬 서비스에 전송하지 않습니다.

## 비교 규칙

- 종류와 단위가 같은 결과를 최대 2개 선택합니다. 암묵적 단위 변환은 없습니다.
- 곡선은 공통 축에 표시합니다. 표본 좌표와 개수가 정확히 같을 때만 절대 차이를
  계산합니다. 좌표가 다르면 겹쳐 표시만 하며 보간하지 않는다는 안내를 표시합니다.
- 외부 구조는 공통 축척과 재료 색상으로 나란히 표시하며 표에서 영역 좌표를
  확인할 수 있습니다. 참조 도면의 확대 기능이 외부 구조를 수정하거나 계산하지 않습니다.
- 허용 오차, 합격 판정, 승인된 기준선, 검증 결과 내보내기를 추론하지 않습니다.
  결과 제거는 메모리 사본만 제거하며 원본 파일은 삭제하지 않습니다.

## 모의 수명 주기

**참조 워크플로 실행**은 메모리의 상태 전이를 구동합니다. 실행 중 **중단 상황 재현**,
**모의 실행 복구**, **모의 실행 취소**를 사용할 수 있습니다. 실행 중이거나 중단된
동안 프로젝트·덱·바이어스 입력을 잠급니다. 복구는 모의 단계를 유지하며 취소된 작업은
그대로 종료됩니다. 실행 세대로 오래된 타이머 이벤트를 거부하고 최근 20개 전이를 보관합니다.

로컬 서비스 화면에서도 이 경로는 솔버나 실행 API를 호출하지 않습니다. 프로세스 재시작,
OS 재시작, 전원 차단의 내구성을 주장하지 않습니다. 새로고침하면 모의 상태는 초기화됩니다.
기존의 명시적 로컬 연결 버튼은 상태 조회만 수행합니다.

## 검증과 유보 범위

`npm run test:m4`는 파일 계약과 UI 테스트를 실행합니다. `npm run check`에는
기존 프런트엔드·백엔드 테스트와 M4 테스트가 모두 포함됩니다. 정적 모드와 로컬 모드,
키보드·포인터 조작, 프로젝트 교체, 잘못된 파일, 비교 제한, 네트워크 호출 없는
모의 취소·복구를 검사합니다.

M4 독립 기능은 구현되어 있습니다. 실제 솔버 통합, 실행 검증, 제품 활성화는
다음 M3 조건을 충족할 때까지 유보합니다.

1. 검토된 Windows/macOS/Linux × Docker/Podman 자격 검증
2. 요구되는 실제 전원 차단 증거
3. 솔버 권리, 불변 이미지, SBOM, 수치 기준 corpus 승인

M4는 M3 승인 매니페스트, 런타임 권한, 릴리스 프로필, 기존 OpenTCAD OG 이미지를
변경하지 않습니다.
